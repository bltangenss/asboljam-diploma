# ИИ қолдану журналы

Күні: 24.09.2026. Құрал: Codex ассистенті және осы сессиядағы тапсырма агенттері. Бұл журнал студенттің өз авторлық талдауын, университет талабын және қолмен тексеруін алмастырмайды.

| Жұмыс | ИИ көмегі | Нақты тексеру / шектеу |
|---|---|---|
| Берілген файлдарды аудиттеу | TXT, DOCX, XLSX, PDF, ZIP мазмұнын оқу; дубликаттарды, қайшылықтарды және жоқ артефактілерді бөлу | docs/SOURCE_REVIEW_RU.md; сыртқы библиографияның бәрі қайта тексерілді деген мәлімдеме жоқ |
| Backend және worker | SQLAlchemy схема, CSV валидатор, auth, рөлдер, кезек, келісу және экспорт кодын жасау | 16 API интеграциялық тест сәтті; PostgreSQL runtime әлі тексерілмеген |
| ML және сатып алу | Уақыттық белгілер, үш модель, метрикалар, MILP, Decimal қайта тексеруі | 14 есептеу тесті; oracle қолданылмаған |
| Зерттеу артефактілері | Қайта есептеу скрипті және нәтижелер кестелері | Нақты орындалған 9 болжам, 36 сценарий; дерек пен код хэштері тіркелген |
| Резервтік көшіру | SQLite online backup және restore құралы | 4 тест сәтті; PostgreSQL pg_dump бөлек тексеріледі |
| Web/mobile | Клиент коды, интерфейс және API байланысы | Құрастыру/браузер/құрылғы нәтижелері PROGRESS.md ішінде жеке көрсетіледі |
| Инфрақұрылым/нұсқаулық | Compose, Dockerfile, Windows/Linux скрипттері, README | Compose static config тексерілді; Docker daemon жоқ болғандықтан контейнерлер іске қосылмады |

Жасанды деректі нақты кәсіпорын дерегі деп ұсынуға, есептелмеген метриканы қосуға, сұхбат/пайдаланушы пікірін ойдан шығаруға немесе үнемді дәлелсіз мәлімдеуге болмайды. Студент формулаларды, кодты, әдістемені және университеттің ИИ қолдану ережесін өзі қарап, өз түзетулері мен қорытындыларын төменге жазуы керек.

Студенттің кейінгі тексеруі: толтырылмаған.
Қолмен өзгерткен файлдары мен негіздемесі: толтырылмаған.
Университетке берілетін декларацияның соңғы мәтіні: студент/жетекші нақтылайды.
