Задумано: таблица блюд и целых порций, явные нули, название, филиал, целевая дата, причина, публичный автор, время в часовом поясе документа/организации либо явном UTC; заметные SYNTHETIC/TEST и неизвестная свежесть. Данные копируются в память для временной печатной страницы. Печать не делает API-запросов, не списывает склад, не подтверждает приготовление и не отправляет заказ поставщику.

Подготовленные сценарии используют искусственные ответы API и подменённый `window.print`. Настоящий принтер, PDF, физическая пагинация и Safari не проверены. В браузерах с неблокирующим `window.print` жизненный цикл требует дополнительной проверки: нельзя обещать работоспособность на всех движках.
