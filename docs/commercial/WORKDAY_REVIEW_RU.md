# Predas: сверка рабочего дня — сохранённый незавершённый этап 2

19.10.2026 пользователь попросил сохранить, отправить изменения и остановиться. Это точка продолжения, не завершённый этап и не release.

## Что добавлено

- Миграция `0012` создаёт пустые `working_plan_selections`, `reconciliation_snapshots`, `notification_receipts`. Прежние планы автоматически не выбираются, прежние факты не создаются.
- `GET/POST /api/v1/working-plan`: явный рабочий вариант дня, версия, структурированная причина и текст, автор, время, история и точная квитанция повторного запроса. Выбор не меняет закупки, прогнозы и склад.
- `GET /api/v1/forecast-review`: сравнение сохранённого прогноза, выбранного варианта и закрытого факта; MAE, WAPE, bias, интервальное покрытие, пропуски и stockout отдельно. Ноль не заменяет отсутствие строки. `POST /forecast-review/refresh` явно сохраняет снимки, GET не пишет. Закрытие дня и повторное открытие сохраняют снимки в своей транзакции; прежний снимок доступен через `/forecast-review/history/{id}`.
- Правило выбора прогноза: последний созданный расчёт, завершённый и опубликованный до местной полуночи целевого дня; при отсутствии такого расчёта показана историческая сверка. SYNTHETIC и REAL/TEST исключаются из бизнес-метрик. Поправка сравнивается с исходным прогнозом именно её варианта.
- `GET /api/v1/workday-tasks`: условия текущего дня и готовность данных с устойчивыми идентификаторами. `POST /workday-tasks/{id}/view` отмечает просмотр только этим пользователем. Просмотр не устраняет проблему и не утверждает закупку. Исчезнувшая причина убирает задачу; изменение исходных сведений создаёт новый ключ. SYNTHETIC привязан к 01.01.2026.
- В деталях прогноза `explanation` восстанавливает основу baseline и значения признаков из сохранённого `Job.snapshot`, проверяя хеш истории. Текущие изменяемые продажи не используются. Это объяснение входных данных, не причинное разложение прогноза. Без сохранённого подходящего snapshot объяснение явно недоступно.
- Web KK/RU: задачи и готовность на «Сегодня», раскрываемая сверка и её история, выбор рабочего варианта в плане приготовления, пояснения к прогнозу. Добавлены восемь сценариев Playwright.

- Текущий REAL API разрешает `origin` только после окончания календарного дня. Поэтому обычный прогноз появляется уже после полуночи целевой даты и не удовлетворяет строгому правилу заблаговременной оценки. Код явно возвращает `NEXT_DAY_CUTOFF_REQUIRES_SCHEDULING`; границу нельзя менять молча ради появления метрик.
