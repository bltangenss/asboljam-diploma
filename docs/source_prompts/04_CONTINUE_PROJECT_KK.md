# Жұмысты басқа чатта не басқа құралда жалғастыру

AsBoljam жобасын осы репозиторийден жалғастыр. README_KK.md, AGENTS.md, templates/PROGRESS.md, templates/DECISIONS.md, contracts/openapi.json және соңғы тест журналын алдымен оқы. prompts/01_BUILD_WEBSITE_KK.md — негізгі мақсат, prompts/02_DESIGN_KK.md — UI/UX талаптары.

Алдыңғы чаттың «дайын» деген сөзіне емес, нақты файлға, іске қосылатын кодқа және тестке сүйен. Файлдарды тексермей жобаны нөлден қайта жазба. Бар API/DB сәйкестігін сақта. Келісімшарт өзгерсе, себебін DECISIONS-ке, миграциясын кодқа, клиент түрлендіруін тестке қос.

Осы жинақтың бастапқы күйінде тек спецификация, дерек дайындаушы, демо-база, JSON fixtures және бұрынғы есептеу коды бар. Веб-интерфейс, production API, mobile build және сыртқы интеграция іске асырылмаған.

Келесі аяқталмаған кезеңді таңда, кодта, тексер. Соңында өзгерген файлдар, орындалған пәрмендер, олардың нақты нәтижесі және келесі шағын қадамды PROGRESS-ке жаз. SYNTHETIC деректі нақты дерекке, біркүндік есепті көпкүндік модельге немесе mock экранды жұмыс істейтін API-ге айналдырып сипаттама.
