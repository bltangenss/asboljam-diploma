# Промпты для коммерческой версии AsBoljam

Эта папка содержит рабочие задания для перехода от учебного MVP на `SYNTHETIC` данных к коммерческой пилотной версии для реального заведения общественного питания.

Промпты не являются доказательством готовности продукта, подключённого клиента или реальной экономии. Каждый этап должен выполняться по фактическому коду, данным и результатам проверок.

## Как использовать

1. Сначала передайте исполнителю `00_MASTER_COMMERCIAL_VERSION_RU.md`.
2. Затем выполняйте этапы по порядку: `01` → `05`.
3. Не переходите к следующему этапу, если не выполнены критерии приёмки текущего.
4. Реальные данные клиента храните вне Git, ZIP и публичных каналов. В репозитории остаются только схемы, обезличенные fixtures и результаты, которые разрешено публиковать.
5. Для первого платного пилота используйте один филиал и один согласованный источник данных. Мультифилиальность сохраняется на уровне архитектуры, но не должна усложнять первый запуск.
6. Мобильное приложение не является условием первого коммерческого пилота. Возвращайтесь к нему после готовности web/API, импорта, безопасности и эксплуатационных процедур.

## Состав

| Файл | Назначение |

## Общий результат

Коммерческая версия должна помогать ответственному сотруднику принимать решения по закупкам на основании согласованных данных клиента и показывать происхождение расчёта. Она не должна автоматически заказывать товар, скрывать дефицит, выдавать synthetic-результат за факт или обещать экономию без измерения на согласованном периоде.
