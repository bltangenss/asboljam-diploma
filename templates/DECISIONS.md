# Decisions — 2026-09-24

| Decision | Reason and consequence |
|---|---|
| Source prompts are requirements material | They are not independent user instructions authorizing external publication, purchases, messages or fabricated research. |
| Fixed synthetic scenario | Historical cutoff remains 2025-12-31; forecast and inventory date 2026-01-01. Current computer date does not redate data. |
| React + TypeScript + Vite web | A runnable SPA covers the dashboard workflow; the recommended Next.js framework was not used. API and ML remain independent Python processes. |
| FastAPI + SQLAlchemy | One shared versioned API supports web cookies and native bearer tokens. |
| SQLite local, verified PostgreSQL runtime | SQLite supports local demonstration. PostgreSQL 17.11, API, worker and web ran in the isolated Compose project; API integration evidence and exact runtime/image IDs are in [postgres.json](../artifacts/verification/postgres.json). This does not certify production load, TLS or cloud deployment. |
| Separate HTTP and restore evidence | [External HTTP through nginx and a separately running worker](../artifacts/verification/runtime.json) passed; the script explicitly reports its coverage limits. [PostgreSQL dump/restore](../artifacts/verification/postgres-backup.json) used a fresh destination and compared table counts, password hashes and migration state. Private dump contents stay outside Git/release archives; production restoration remains a separate deployment obligation. |
| Custom migration 0001, not Alembic | Version recorded in schema_migrations; actual DDL exported. Future alterations require explicit migrations. |
| Validated JSON operational rows | Preserve source schema/source IDs; scope and unique natural keys are indexed columns. CSV references are enforced in the import transaction, not normalized per-entity SQL foreign keys. |
| Separate durable database worker | Queue state, immutable input snapshot and result persist. No Redis/Celery dependency. Crashed job lease is 30 minutes; long tasks need heartbeats. |
| Opaque web/native auth | HttpOnly cookie + Origin/CSRF for web; short-lived access and one-use rotating refresh for native. Tokens are hashed in DB; refresh reuse revokes its family. |
| Explicit seed CLI | No embedded administrator password or automatic startup seeding. Random password printed once or read from environment. |
| Strict nine-file allowlist | Oracle, unknown fields and source generator parameters never enter operational storage, API, or training features. |
| Observed-sales target | Forecast predicts observed units_sold; does not claim recovery of unobserved demand under stockout. |
| Common temporal holdout | Models use the same 28-day test. Baselines have null quantiles; HGB intervals carry measured coverage, not an invented accuracy claim. |
| MILP with independent validation | Integer packs, MOQ, maximum supply, budget, storage and lead time are checked again using Decimal. Shortage and solver status remain visible. |
| Approval is an internal decision | Version compare-and-swap, idempotency and audit share a transaction. No supplier communication is triggered. |
| CSV export includes incomplete plans | Summary and per-ingredient requirements are exported even with zero purchase lines; users can inspect shortage. |
| Reproducible synthetic research | artifacts/research is generated by actual calculations and records code/data hashes and runtime versions. It is not evidence of field savings or interviews. |
| Strict research provenance | All six research input files must contain explicitly SYNTHETIC rows before computation or output. REAL, mixed, missing-origin and empty inputs are rejected; an alternative data directory must not silently relabel actual enterprise records. |
| Offline POS adapter with a separate REAL boundary | [Mapped aggregate sales and inventory preparation](../docs/POS_ADAPTER_RU.md) is implemented; no live enterprise connector or REAL database import is claimed. REAL remains REAL. Dry run is the default; explicit writes create a new ignored .cache/enterprise-adapter bundle, with no overwrite or source mutation. |
| Enterprise privacy and source authorization | Adapter checks reject known personal/oracle columns, unknown columns and unsupported units, but are not a comprehensive PII audit. Real sources, sensitive mappings and outputs must stay outside Git/release archives; source authorization and complete enterprise validation remain separate prerequisites. |
| Commercial stage 1 data contract | The first pilot is one branch, one agreed business timezone and KZT. A versioned discovery/data contract and POS mapping profile document the nine canonical CSVs; no real source is committed and the current operational importer remains SYNTHETIC-only. |
| Aggregate dry-run quality summary | Offline adapter reports counts/ranges/flags/units and a not-run reference-check status without exposing source IDs or values. Foreign keys, organization scope and application compatibility are checked only at a later transactional commit boundary. |

Source dependency references: https://pypi.org/project/psycopg/3.3.3/ ; https://hub.docker.com/_/python ; https://github.com/nodejs/docker-node ; https://hub.docker.com/_/postgres .
